# Y Hema Sudarshan — AI & ML Portfolio

Modern, interactive portfolio showcasing Artificial Intelligence, Machine Learning, Data Analytics, and Backend Engineering projects.

## 🚀 Features

- **Cyberpunk Dark Theme & Custom Glow:** Smooth mouse tracking glow, neon accents, and backdrop blur glassmorphism.
- **3D Tilt Interaction:** Dynamic perspective tilt cards powered by pointer events.
- **Interactive Project Showcase:** Highlighting flagship AI/ML, RAG, and Computer Vision builds with direct GitHub repository links.
- **Responsive Navigation:** Clean mobile navigation drawer and desktop quick-access links.
- **Custom Branded SVG Assets:** Modern icons and custom favicon matching the neural aesthetic.

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Styling:** Vanilla Modern CSS (CSS Variables, Flexbox, CSS Grid)
- **Icons:** Lucide Icons & Custom SVG Icons

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/Sudarshan-939/Portfolio.git

# Navigate into the project
cd Portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production
npm run build
```
